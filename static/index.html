临床实验室质量控制与结果拦截

质控规则、仪器校准、失控调查和患者结果批次通过JSON接口管理；检测项目、质控品批次、患者结果批次按专业组归属，跨组操作直接拒绝并记录。

等待操作
GET  /health
GET  /api/<kind>                          # assay / qc_lot / result_batch / lab_group ...
POST /api/<kind>
POST /api/entities/<id>/actions
POST /api/entities/<id>/assign-group     # 指派/调整专业组归属（改组级联冻结相关批次）
POST /api/group-assignments/process       # 总务组逐条处理待指派队列
POST /api/group-assignments/retry         # 失败条目续跑重试
GET  /api/group-assignments?status=pending|failed
GET  /api/group-violations                # 跨组越权记录（是谁、从哪组到哪组）
GET  /api/audit

身份头：X-User-Id / X-Role / X-Group-Id（默认 general 总务组）
